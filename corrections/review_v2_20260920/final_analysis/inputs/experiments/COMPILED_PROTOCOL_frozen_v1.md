# Fresh compiled-resource protocol

This protocol is separate from the uploaded exploratory experiments. `compiled_study.py freeze` records the complete implementation hash, configuration, software versions and UTC time **before** calling the evaluation generator. It writes the generated instances and a hash-linked generation audit. Runs refuse source changes after freezing. This is a prospective local freeze, not an external preregistration.

## Population and primary contrasts

Thirty independent instances each are generated for (i) five-clause Max3SAT on six variables, with distinct uniformly sampled clause supports and independently sampled signs; (ii) five-term cubic Ising spin glasses on six variables, with distinct uniformly sampled supports and independent unit signs; and (iii) four-leaf positive pair-stars plus a disjoint positive triple on nine variables, with random vertex labels and independent weights from {0.75, 1, 1.25}. Spin objectives are divided by eight after converting spins to Boolean variables. The third family is a constructed mechanism study, not a random-problem population estimate. No instance is retained or discarded according to its compiler result.

Primary contrasts are (1) strict-mixed-only joint-budget feasibility, with logical certificates excluding every full reduction whenever available, (2) the same compiled resource score under the same candidate budget for mixed and fully reduced search, and (3) representation-rank and Pareto-set stability between two compilation strategies. No QAOA-quality claim follows from this experiment.

## Exact representation and compiler

Each of the five cubic terms has four actions: retained natively, or assigned to one of its three incident pairs. Shared pairs use one auxiliary each. The Rosenberg coefficient is 1.1 times the larger of the positive and negative bucket masses, strictly above the exact threshold. Both search spaces use this identical policy.

We construct the actual symbolic-gamma cost circuit from the aggregated Pauli expansion. Each Z support is synthesized with a compute/RZ/uncompute parity gadget. Canonical synthesis orders supports by size and lexical order and targets their last qubit. Reuse synthesis chooses the most frequently incident qubit as each gadget's root, groups commuting gadgets by root, and orders parity supports greedily by symmetric difference. Both circuits have no gadget barriers. Qiskit optimization level 3, a CX/RZ/SX/X basis, SABRE routing, seed 1729, and fixed identity initial placement permit cross-gadget optimization. The coupling maps are bidirectional line-12, ring-12 and 3-by-4 grid-12, all with equal physical capacity. Selection is repeated for every topology and strategy, using that target's actual compiled metrics. This is one pinned Qiskit version with two synthesis strategies, not evidence from independent compiler implementations or a compiler-seed distribution.

G is compiled CX count; D is CX-only scheduled circuit depth, with unit-duration CX layers. Neither is wall-clock latency. Total gate count and depth are additionally retained. Width Q counts the occupied input sites plus every physical site touched by the routed circuit; logical width n+r is retained separately. Routing through an initially idle site therefore consumes the width budget. The full device capacity remains 12. The cost layer alone is compiled; state preparation and mixers are outside these resource counts.

## Fair search and controls

Both search spaces score exactly 32 feasible candidates on every target, with identical J=(r/4+G/160+D/120+M/8)/4. Full reduction restricts every action to a pair. The mixed search allows all four actions, including endpoints. Both include the same minimum-auxiliary, maximum-reuse and distance-aware full candidates; mixed additionally includes native, common-pair buckets and maximum-reuse prefixes. Remaining candidates are drawn once from a deterministic random permutation, then reused across compiler strategies. This is a bounded candidate search, not a beam algorithm or a proof of a global optimum. Candidate cardinality and cost metrics are equal; candidate construction differs because the search domains differ. Compiler memoization shares identical evaluations without giving either selector extra candidates. All 3^5 full assignments are enumerated logically to determine the exact minimum auxiliary count and whether width/penalty alone exclude the full endpoint.

The minimum-auxiliary baseline asks whether auxiliary count alone accounts for the result; maximum reuse tests reuse alone; the resource-optimized full baseline isolates allowing partial reduction under comparable search effort. The distance-aware full baseline minimizes original-pair graph distance, then maximizes reuse. It is a bespoke inspired comparator, not a faithful implementation of a named hardware-aware algorithm. For cubic-only instances, the reuse component of triangle-chain substitution reduces to selecting a maximum-occurrence pair; no higher-degree term survives to require a second substitution stage.

A separately compiled random control matches both the auxiliary count and reduced-term count of the best strict mixed candidate. It also matches the exact penalty maximum when a distinct matching candidate exists. The control is chosen without observing its compiler score. Absence of a distinct match is reported as degeneration. The random control does not enter either selector or the feasibility archive.

## Budgets and interpretation

The grid is fixed before generation: Q=6,...,12; G=0,4,...,240; D in {24,48,72,96,120,160,240}; M in {0,1.1,2.2,3.3,4.4,6.6,8.8}. Every cell is classified using native, all 32 searched full candidates, and all strict mixed candidates in the 32-design mixed archive. The five labels are both endpoints, native endpoint only, full endpoint only, strict mixed only, or none found. An endpoint-only label concerns endpoint feasibility; mixed candidates can also be feasible there. Cells outside the sampled library are unsearched, so “none found” is not a global infeasibility theorem. Strict-mixed-only cells receive an additional certificate flag when exhaustive full logical enumeration excludes every full assignment under the same Q and M budgets, while the compiled native violates G or D. These certified cells do not depend on search completeness for endpoint exclusion.

The Q/G figures are slices at declared D/M values. Any representative-instance illustration must be selected by a predeclared identifier or explicitly labelled post-hoc illustration; population claims use all 30 independent instances per family. Cell counts are descriptive and strongly correlated; they are not independent statistical observations. Representation ranks use common candidate identifiers and Spearman correlation; Pareto sets use (Q,G,D,M) and Jaccard overlap. Report whether the selected representation changes, rather than assuming stability.

## Verification and reproduction

Before freezing, exhaustive bit enumeration verifies all 16 representations of a signed two-term development instance. Logical-circuit phase equality is checked for both synthesis strategies. Routed circuits are checked against the target coupling edges and statevector phases after accounting for final layouts on all three topologies. `compiled_study.py verify`, `freeze`, and `run --workers 4` execute these stages. Results include every candidate's actions and metrics, all logical full assignments, selected baselines, raw circuit-call counts and software version.
